================================================================================
ARCHITECTURE DU CACHE
================================================================================

CalculNotesAnnexesMain
├── balances (DataFrames)          # Cache des balances brutes
│   ├── balance_n                  # Exercice N
│   ├── balance_n1                 # Exercice N-1
│   └── balance_n2                 # Exercice N-2
│
├── balances_dict (Dictionnaires)  # Index pour O(1)
│   ├── {numero: données}          # Balance N
│   ├── {numero: données}          # Balance N-1
│   └── {numero: données}          # Balance N-2
│
└── cache_resultats                # Cache des calculs
    └── {cle: resultat}            # Résultats réutilisables

================================================================================
GAINS DE PERFORMANCE
================================================================================

AVANT (sans cache):
- Chargement par note: ~2-3 secondes
- 33 notes × 2.5s = ~82.5 secondes de chargement
- Accès aux comptes: O(n) via DataFrame
- Calculs répétés: recalculés à chaque fois

APRÈS (avec cache):
- Chargement unique: ~2-3 secondes
- Chargements suivants: ~0.001 secondes
- Économie: ~80 secondes sur 33 notes
- Accès aux comptes: O(1) via dictionnaire
- Calculs répétés: réutilisés depuis le cache

GAIN TOTAL: ~80 secondes économisées + accès optimisés
