================================================================================
CONFIGURATION
================================================================================

Rotation:
  - Fréquence: Quotidienne (minuit)
  - Rétention: 30 jours
  - Compression: Automatique (.gz)
  - Taux de compression: ~70-90%

Format:
  YYYY-MM-DD HH:MM:SS | LEVEL | module | function:line | message

Exemple:
  2026-04-28 14:30:15 | INFO | balance_reader | charger_balances:45 | Chargement de la balance N

================================================================================
UTILISATION
================================================================================

Configuration initiale (une fois au démarrage):
  
  from Modules.logging_config import setup_logging
  setup_logging(log_directory="logs")

Utilisation dans un module:
  
  from Modules.logging_config import get_logger
  
  logger = get_logger(__name__)
  logger.info("Message d'information")
  logger.warning("Message d'avertissement")
  logger.error("Message d'erreur")
