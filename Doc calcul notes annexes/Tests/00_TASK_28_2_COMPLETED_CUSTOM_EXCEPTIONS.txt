All 6 custom exceptions have been successfully implemented for the

EXCEPTIONS IMPLEMENTED
---------------------

1. BalanceNotFoundException
   - Raised when required balance worksheets are missing
   - Provides: missing_sheets, available_sheets
   - Used by: Balance_Reader

2. InvalidBalanceFormatException
   - Raised when balance format is invalid
   - Provides: missing_columns, expected_columns, sheet_name
   - Used by: Balance_Reader

3. InvalidJSONException
   - Raised when JSON file is invalid
   - Provides: file_path, json_error
   - Used by: Mapping_Manager

4. FilePermissionException
   - Raised when file access is denied
   - Provides: file_path, operation
   - Used by: All file operations

5. EmptyBalanceException
   - Raised when balance has no data
   - Provides: sheet_name, row_count
   - Used by: Balance_Reader

6. InvalidAccountNumberException
   - Raised when account number is invalid
   - Provides: account_number, expected_format, line_number
   - Used by: Account_Extractor
