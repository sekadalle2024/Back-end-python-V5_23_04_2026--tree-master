ERREUR PRINCIPALE: Import Relatif
----------------------------------
Message: "attempted relative import with no known parent package"

Fichiers affectés:
- calculer_note_3a.py, 3b.py, 3c.py, 4.py, 5.py, 6.py, 7.py, 8.py, 9.py, 10.py
- calculer_note_11.py à 25.py, 28.py, 29.py, 30.py, 31.py, 32.py

Cause:
Les scripts utilisent des imports relatifs comme:
  from ..Modules.balance_reader import BalanceReader
  from ..Modules.account_extractor import AccountExtractor

Mais sont exécutés comme scripts standalone par l'orchestrateur via:
  module = __import__(module_name)

Solution requise:
1. Modifier les imports dans les calculateurs pour utiliser des imports absolus
2. OU modifier l'orchestrateur pour exécuter les calculateurs comme modules
3. OU ajouter le chemin parent au sys.path avant l'import
