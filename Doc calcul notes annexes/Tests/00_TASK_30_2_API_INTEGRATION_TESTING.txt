TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

ISSUE: Backend not responding
SOLUTION:
- Check backend is running: python py_backend/main.py
- Verify port 5000 is not in use
- Check firewall settings

ISSUE: File upload fails
SOLUTION:
- Verify file format is .xlsx or .xls
- Check file size < 10 MB
- Ensure balance file has correct structure

ISSUE: Processing takes > 30 seconds
SOLUTION:
- Check system resources (CPU, memory)
- Verify balance file is not too large
- Consider enabling parallel processing

ISSUE: Accordions not displaying
SOLUTION:
- Check browser console for errors
- Verify NotesAnnexesAutoTrigger.js is loaded
- Check CSS file is loaded
- Inspect network tab for API response

ISSUE: Invalid coherence rate
SOLUTION:
- Verify balance file has correct data
- Check for missing accounts
- Review balance coherence (N-1 closing = N opening)
