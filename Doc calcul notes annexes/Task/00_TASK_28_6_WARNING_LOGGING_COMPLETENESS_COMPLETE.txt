VALIDATION APPROACH
================================================================================

For Each Warning:
1. Generate random test data using Hypothesis
2. Emit warning using convenience function
3. Read calcul_notes_warnings.log from temp directory
4. Verify:
   ✓ Warning type name present in log
   ✓ All context fields present (compte, montants, note_numero)
   ✓ Timestamp included (YYYY-MM-DD HH:MM:SS format)
   ✓ Log level is WARNING
   ✓ Format is consistent across all warnings
   ✓ No duplication (each warning logged exactly once)

Expected Log Format:
TIMESTAMP | WARNING | LOGGER | LOCATION | [WarningType] message | Context: key=value, ...
