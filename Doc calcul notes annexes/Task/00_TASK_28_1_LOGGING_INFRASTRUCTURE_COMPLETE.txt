SYSTÈME DE LOGGING
================================================================================

Fichiers de logs:
  • calcul_notes_annexes.log     → Tous les logs (INFO, WARNING, ERROR)
  • calcul_notes_warnings.log    → Avertissements uniquement
  • calcul_notes_errors.log      → Erreurs uniquement

Configuration:
  • Rotation: Quotidienne à minuit
  • Rétention: 30 jours d'historique
  • Compression: Automatique (.gz, ~70-90% de réduction)
  • Format: YYYY-MM-DD HH:MM:SS | LEVEL | module | function:line | message

================================================================================
UTILISATION RAPIDE
================================================================================

Configuration au démarrage:
  
  from Modules.logging_config import setup_logging
  setup_logging()

Dans vos modules:
  
  from Modules.logging_config import get_logger
  
  logger = get_logger(__name__)
  logger.info("Message d'information")
  logger.warning("Avertissement")
  logger.error("Erreur critique")
