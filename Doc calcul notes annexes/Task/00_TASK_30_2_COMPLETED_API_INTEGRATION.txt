TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

COMMON ISSUES:

1. Backend Not Responding
   - Check: python py_backend/main.py is running
   - Verify: Port 5000 is available
   - Review: Backend logs for errors

2. File Upload Fails
   - Verify: File format is .xlsx or .xls
   - Check: File size < 10 MB
   - Ensure: Balance file has 3 worksheets (N, N-1, N-2)

3. Processing Timeout
   - Check: System resources (CPU, memory)
   - Verify: Balance file is not too large
   - Consider: Closing other applications

4. Accordions Not Displaying
   - Check: Browser console for errors (F12)
   - Verify: NotesAnnexesAutoTrigger.js is loaded
   - Inspect: Network tab for API response
   - Clear: Browser cache and reload

5. Low Coherence Rate
   - Verify: Balance file has correct data
   - Check: Missing accounts
   - Review: Balance coherence (N-1 closing = N opening)
